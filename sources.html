文化部展覽開放資料

文化部 2026「展覽資訊」，原始資料版本保留於各筆紀錄（sourceVersion），最新擷取日期與成功時間見更新狀態。來源：政府資料開放平臺展覽資訊。

此開放資料依政府資料開放授權條款第1版進行公眾釋出，使用者於遵守本條款各項規定之前提下，得利用之。本站正規化名稱、日期、場地、票價等基本欄位，摘要由本站獨立整理，不使用原始完整簡介、點閱數、照片或海報。

政府資料授權不表示任意第三方圖片、商標或其他素材均可自由使用。本站連結的官方頁面及其中第三方素材，權利仍屬各權利人；本站不搬存或展示這些素材。來源提供機關未對本網站表示推薦、同意或背書。

松菸、華山與駁二：初始人工核對與每日公開頁面整理

松山文創園區展演資訊、華山1914展演活動為固定入口。2026-10-05本次逐筆整理松菸16筆、華山18筆及駁二官方展演基本事實與自行摘要，不複製官網的長文或海報，並連回每筆官方詳情。華山其中8筆官方分類為歷史活動，公告日期卻仍在展期內，均標示狀態待確認並排除近期推薦。駁二入口：官方展演清單。三場館使用正常公開頁面每日整理名稱、日期與地點，摘要由本站以基本事實自行產生。松菸 robots 允許公開頁面；華山禁止 query 分頁及 API，只讀公開首頁及已收錄的無 query 詳情，不承諾完整；駁二以正常瀏覽器讀公開展演頁，不另呼叫內部 API，阻擋海報與媒體載入。各網站仍保留文案、圖像等權利，本站不搬運；本網站無廣告或商業服務。票價沒有明確結構化欄位時標為未提供或前次人工核對，不能當成每日確認票價。官方政策改變、存取失敗或解析不完整時，保留該來源最後成功資料並顯示失敗及時間。

活動來源連結

文化部 API 的推廣網址不一定是活動詳情。本站只將已核對活動名稱的來源頁列為「活動資訊／來源網站」。未確認者明示尚無有效詳情，連到官方資料集並提供 UID，方便向主辦單位查詢。文化部 iCulture 詳情服務目前可能出現 502 或逾時；外部網站後續仍可能變更。新活動、名稱或網址變更後，未重新核對的連結不會自動標為詳情。

日期、價格與推薦

首次收錄日不等於公告日。展期內可能休館，票價與參加條件仍請查官方。推薦依地區及近期展期排序，不表示人氣、品質評價或官方推薦。缺少票價的紀錄會標示未提供，不推定免費。歷史從本站開始收錄累積。

展覽清單與狀態使用同一份完整快照，來源失敗時保留最後成功資料並標示失敗。來源暫時不提供的活動不推定取消；名稱或展期更正保存在 revisions，維持首次收錄日。
