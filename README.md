# 展覽散步 · Taiwan Exhibition Tracker

獨立、無框架、無付費服務的繁中靜態網站。原生 HTML/CSS/JS，Python 更新器，場館解析使用 BeautifulSoup／Playwright 及環境既有 Chrome，無 API key。

資料來源為[文化部2026「展覽資訊」](https://data.gov.tw/dataset/6012)，原始版本（目前1.4）保留在各筆sourceVersion，擷取日期見data/exhibitions.json的sources.moc.lastSuccess。此開放資料依[政府資料開放授權條款第1版](https://data.gov.tw/license)進行公眾釋出，使用者於遵守各項規定之前提下，得利用之。本站僅整理基本事實與自行摘要，不搬運完整簡介或海報，不暗示官方背書；第三方素材的權利不因政府資料授權而自動涵蓋。另有2026-10-05本次松菸16筆、華山18筆、駁二12筆官網核對的基本事實與本站自寫摘要。華山8筆日期與歷史分類矛盾，標示待確認並排除近期推薦。詳見[本次場館核對清單](docs/VENUE_REVIEW.md)。

## 本機啟動

在本專案資料夾執行（Python 3.10+）：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

開啟 http://127.0.0.1:8765 。不要直接雙擊 HTML，瀏覽器會限制讀取 JSON。

```powershell
python -m pip install -r requirements-update.txt
python scripts/update_venue_sources.py
python scripts/update.py
python -m unittest discover -s tests -v
node --check app.js
```

更新器成功 exit 0，失敗 exit 1。失敗仍寫入來源狀態並保存最後成功的展覽與時間，適合由 CI 發布失敗狀態；首次完全失敗時只顯示已核對的固定場館資料。對外網路須允許 cloud.culture.tw，不修改安全設定或繞過 TLS。Python3.13對官方較舊憑證鏈的嚴格RFC檢查可能報Missing Subject Key Identifier，此時改由系統curl以預設TLS憑證／主機名稱驗證讀取同一HTTPS來源；不使用--insecure，不改信任庫。GitHub runner與Windows10/11已有curl，不需付費服務或新金鑰。

## 使用方式

- 預設全台，台北／新北優先。地區、指定日期、場館、名稱／地點可組合篩選。
- 今日新增是台灣時間的「本站首次收錄日」，不是活動公告日；首次匯入的大批展覽會一併列入。
- 近期推薦：展期與未來30天重疊，先台北／新北、再依開展日期。不計人氣、不使用點閱數。
- 即將結束：已開始且14天內結束。日期以展期為準，休館日仍須查看官方。
- 歷史紀錄：所有已結束的已收錄展覽；從本網站開始累積，無法重建 API 沒提供的過去資料。
- 松菸、華山、駁二是固定官方入口，已沿用台灣09:00每日流程讀取允許的公開頁面及基本欄位。華山禁止 query 分頁/API，僅首頁及已收錄詳情；不能聲稱全量。各來源失敗獨立保留最後成功資料，票價依卡片標示核對。[每日場館流程及限制](docs/DAILY_VENUES.md)。

## 來源與可靠性

詳見 [來源決策](docs/SOURCES.md)、[網站授權說明](sources.html) 及 [每日更新／Pages workflow](.github/workflows/update-and-deploy.yml)。排程是UTC01:00＝台灣09:00，GitHub可能延遲執行。已附真實官方資料快照，沒有展示用假活動；測試資料只在暫存資料夾內。

資料檔 `data/exhibitions.json` 是單一完整快照，包含來源健康狀態、各筆來源版本、首次／最後收錄時間。瀏覽器直接讀這個檔案，因此失敗狀態與清單一致。`status.json` 是供維運使用的副本。

更新有30秒 timeout、最多3次重試、10MB上限、HTTPS host 檢查、日期／分類／地點檢查、空資料與20%以上異常列拒絕、既有活躍資料量下降逾50%拒絕。文化部 UID＋地點作穩定識別，同一場地多場次合併展期；跨來源再按標題、地區、展期去重。消失的資料保留並標記，不臆測取消。名稱／展期／票價改動保留在每筆 revisions 欄位，維持原首次收錄日，避免誤列新增。資料檔以同目錄暫存檔原子替換；請勿同時執行多個更新器，CI 使用 concurrency。

官網連結只允許 http/https，不輸出原始 HTML、不抓海報、不搬運全文。文化部推廣網址不一定是活動詳情，僅已核對活動名稱的來源頁顯示「活動資訊／來源網站」。未確認者顯示「文化部資料集來源」及 UID，明示沒有有效詳情，不自行拼接網址。新活動、名稱或來源網址變更均須重新核對，避免每日更新重新引入錯誤連結。[來源連結修正與驗證](docs/SOURCE_LINKS.md)。

同一每日流程也輪替核對曾成功驗證的文化部官方詳情候選，每次最多三頁、失敗即停止。使用環境既有瀏覽器，活動標題符合才恢復有效詳情；故障或缺少瀏覽器時維持最後成功資料及明示資料集入口，不新增排程。

## 已知限制

文化部涵蓋全台各地但不是所有展覽。純欄位生成的簡介偏保守，未從長文推斷策展特色。場館官網文案與圖像仍保留權利；每日只整理允許公開頁面的基本事實，原創摘要由基本欄位生成，不做全站或禁止 API 抓取。日期範圍不代表每天開放，票價空白明確標未提供。資料超過36小時會提醒陳舊；免費 GitHub Actions 排程可能延遲，無法保證整點更新。


所有活動地點均納入地區連動的場館選單，含博物館、藝廊、圖書館等。[場館分類規則及缺漏](docs/VENUES.md)。僅有行政區或地址的紀錄明示待確認／地址地點，原始展廳資訊保留。回歸：`python scripts/venue_regression.py`，可用`--url`檢驗公開站。
