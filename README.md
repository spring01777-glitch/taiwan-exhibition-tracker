# 展覽散步 · Taiwan Exhibition Tracker

獨立、無框架、無付費服務的繁中靜態網站 MVP。原生 HTML/CSS/JS，Python 標準函式庫更新器，無 API key。

資料來源為[文化部2026「展覽資訊」](https://data.gov.tw/dataset/6012)，原始版本（目前1.4）保留在各筆sourceVersion，擷取日期見data/exhibitions.json的sources.moc.lastSuccess。此開放資料依[政府資料開放授權條款第1版](https://data.gov.tw/license)進行公眾釋出，使用者於遵守各項規定之前提下，得利用之。本站僅整理基本事實與自行摘要，不搬運完整簡介或海報，不暗示官方背書；第三方素材的權利不因政府資料授權而自動涵蓋。另有4筆松菸／華山官網人工核對的基本活動事實與官方連結。

## 本機啟動

在本專案資料夾執行（Python 3.10+）：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

開啟 http://127.0.0.1:8765 。不要直接雙擊 HTML，瀏覽器會限制讀取 JSON。

```powershell
python scripts/update.py
python -m unittest discover -s tests -v
node --check app.js
```

更新器成功 exit 0，失敗 exit 1。失敗仍寫入來源狀態並保存最後成功的展覽與時間，適合稍後由 CI 發布失敗狀態；首次完全失敗時只顯示已核對的固定場館資料。對外網路須允許 cloud.culture.tw，不修改安全設定或繞過 TLS。

## 使用方式

- 預設全台，台北／新北優先。地區、指定日期、場館、名稱／地點可組合篩選。
- 今日新增是台灣時間的「本站首次收錄日」，不是活動公告日；首次匯入的大批展覽會一併列入。
- 近期推薦：展期與未來30天重疊，先台北／新北、再依開展日期。不計人氣、不使用點閱數。
- 即將結束：已開始且14天內結束。日期以展期為準，休館日仍須查看官方。
- 歷史紀錄：所有已結束的已收錄展覽；從本網站開始累積，無法重建 API 沒提供的過去資料。
- 松菸、華山是固定官方入口，少量資料人工核對，另有場館篩選。文化部資料若有這些場館則也會自動納入。**尚未完成兩場館官網的全量自動新活動抓取**，不可聲稱覆蓋完整。

## 來源與可靠性

詳見 [來源決策](docs/SOURCES.md)、[網站授權說明](sources.html) 及 [每日更新／Pages workflow](.github/workflows/update-and-deploy.yml)。排程是UTC01:00＝台灣09:00，GitHub可能延遲執行。已附真實官方資料快照，沒有展示用假活動；測試資料只在暫存資料夾內。

資料檔 `data/exhibitions.json` 是單一完整快照，包含來源健康狀態、各筆來源版本、首次／最後收錄時間。瀏覽器直接讀這個檔案，因此失敗狀態與清單一致。`status.json` 是供維運使用的副本。

更新有30秒 timeout、最多3次重試、10MB上限、HTTPS host 檢查、日期／分類／地點檢查、空資料與20%以上異常列拒絕、既有活躍資料量下降逾50%拒絕。文化部 UID＋地點作穩定識別，同一場地多場次合併展期；跨來源再按標題、地區、展期去重。消失的資料保留並標記，不臆測取消。名稱／展期／票價改動保留在每筆 revisions 欄位，維持原首次收錄日，避免誤列新增。資料檔以同目錄暫存檔原子替換；請勿同時執行多個更新器，CI 使用 concurrency。

官網連結只允許 http/https，不輸出原始 HTML、不抓海報、不搬運全文。來源 API 中的推廣連結是主辦方提供的活動連結，缺少时退回文化部活動紀錄；本站沒有逐一驗證302個連結的即時可用性。舊的 http 連結可能由官方維護或失效。

## 已知限制

文化部涵蓋全台各地但不是所有展覽。純欄位生成的簡介偏保守，未從長文推斷策展特色。場館官網無已確認開放授權/API，暫不做全站爬取。日期範圍不代表每天開放，票價空白明確標未提供。資料超過36小時會提醒陳舊；免費 GitHub Actions 排程可能延遲，無法保證整點更新。
