# 來源、授權與更新方法

## 文化部：官方開放資料

- API：`https://cloud.culture.tw/frontsite/trans/SearchShowAction.do?method=doFindTypeJ&category=6`。
- [政府資料集6012](https://data.gov.tw/dataset/6012)標示免費、每1日更新，採[政府資料開放授權條款第1版](https://data.gov.tw/license)。保留來源版本與擷取時間，本站正規化基本事實並自行產生摘要，不使用原始全文、點閱數、海報、圖片或私人聯絡資料。
- 每日09:00台灣時間由既有 GitHub Actions 更新；來源故障、空資料、日期錯誤、異常大量減少均保留最後成功資料及成功時間。暫時消失不推定取消；首次收錄、歷史與更正紀錄保留。
- [來源詳情連結核對與恢復](SOURCE_LINKS.md)：已核對來源頁才標示活動資訊；未確認明示官方資料集入口及UID。曾經核對的文化部詳情每次最多三頁輪替重新核對，失敗即停止。

## 三場館：每日允許的公開頁面基本事實

- [松山文創園區](https://www.songshanculturalpark.org/exhibition)：robots允許公開頁面。政策保留智慧財產權且限個人／非商業利用；本站無廣告或商業服務，只使用基本事實與本站原創摘要，不搬運內容或原頁排版。
- [華山1914](https://www.huashan1914.com/exhibition)：robots禁止query、API、搜尋及會員頁。每日僅讀公開首頁及已收錄的無query詳情，不能聲稱活動清單完整；8筆初始資料與官方歷史分類矛盾仍保留待確認提示、排除推薦。
- [駁二藝術特區](https://pier2.org/exhibition/)：[政策](https://pier2.org/privacy/)未列禁止正常公開瀏覽，文案與圖像仍保留權利。robots回404不等於授權內部API；使用正常瀏覽器渲染公開頁面、不直接呼叫內部API，阻擋海報、圖片、字型與媒體載入，不保存原文或DOM至公開檔案。
- [每日方法、狀態與失敗保留](DAILY_VENUES.md)。每來源獨立最後嘗試／成功時間，政策變更、robots限制、瀏覽器不可用或解析失敗均保留該來源最後成功快照，網站及工作紀錄明示失敗。票價未有可靠結構化資料則明示未提供或前次人工核對，不推定免費，不宣稱票價逐日確認。
- [2026-10-05初始人工核對46筆](VENUE_REVIEW.md)屬歷史核對紀錄；當前活動與日期以公開網站快照及官方最新公告為準。[同類場館現況盤點](VENUE_COVERAGE.md)指出其他文化園區的實際收錄及缺口；本輪不新增其他場館每日抓取。

基本事實的利用不涵蓋第三方圖片、商標或文案；來源機關／場館未推薦或背書本站。網站無人氣排序、AI API、付費抓取平台，所有摘要由基本欄位自行生成。日期範圍不保證每天開放，出發前請查官方。
