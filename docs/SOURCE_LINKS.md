# 活動來源連結修正

2026-10-06（台灣時間）核對目前 299 筆文化部活動。原本 125 筆缺少推廣網址時，由程式組合舊版 `showEvent` 路徑；其餘 174 筆直接使用 API 的 `sourceWebPromote`，其中可能是首頁或活動列表，不能一律當作活動詳情。

從 [iCulture 官方首頁](https://cloud.culture.tw/) 實際連結確認現行詳情路徑為 `eventInquiryAction.do?method=showEventDetail&uid=…`。全部 299 個 UID 均符合 24 字元十六進位格式。逐筆 HTTP 核對得到 147 頁活動名稱相符、152 頁無法取得；另用瀏覽器抽查六縣市的現行文化部詳情，均收到 502，因此目前不把這些不穩定深層連結列為可用詳情。

對 API 提供的 136 個不同推廣網址完成核對，其中 44 筆活動全文名稱可在來源頁找到。再以瀏覽器抽查八縣市：台南、新北、台北、台中、彰化、高雄、苗栗七筆可開啟且活動名稱相符；南投逾時，已降級。現在 43 筆使用核對來源頁，256 筆明示尚無有效詳情，連到 [官方資料集](https://data.gov.tw/dataset/6012) 並提供 UID。首頁／列表也可能含多場活動，因此按鈕使用「活動資訊／來源網站」，不保證都是獨立詳情頁。

核對狀態、活動名稱、網址及时间記於 `data/source-links.json`。更新程式要求 UID、名稱及 API 推廣網址完全符合核對紀錄；新活動、改名或換網址一律回到明示資料集來源，不能以未驗證網址冒充活動詳情。未確認不代表活動不存在；官方站仍可能暫時故障。三個園區的人工核對活動連結維持原官方網址。

驗證包含 20 個單元測試、全部文化部來源的快照檢查、桌機／手機按鈕文字與提示、來源說明頁及公開網站點擊抽查。原始網頁、API 完整文案、圖片與瀏覽器暫存不發布。

## 有上限的恢復核對

147 是文化部官方詳情的 HTTP 標題核對數；43 是 API 推廣來源頁的核對數，兩者並非同一口徑。前次六筆瀏覽器詳情均為 502，未將那 147 筆啟用。2026-10-06 後續僅抽查三筆（台中、南投、苗栗），瀏覽器已回傳 200 且活動名稱相符，三筆已恢復，當時共 46 筆可用來源、253 筆資料集入口。HTTP 與瀏覽器仍可能得到不同結果，不能據此宣稱全部恢復。

原每日流程只讀固定核對清單，沒有自動恢復能力。現在沿用同一個每日台灣 09:00 工作，先執行 `scripts/recover_source_links.py`：只從 147 筆曾核對標題的官方詳情候選輪替選取，每次最多三頁、每頁 12 秒、一次失敗即停止；不重試、不增加排程、不新抓其他來源。候選的 UID、網址格式及目前活動名稱都要一致；Chrome／Chromium 實際頁面標題及標題欄都含正確活動名稱才恢復。已核對的推廣來源不受此流程覆蓋。

流程使用執行環境既有 Chrome／Chromium；若不存在、逾時、502、名稱不符或目前活動已改名，保留資料集入口與最後成功核對資料，在工作紀錄明示結果。不安裝瀏覽器，不關閉 TLS 或瀏覽器沙箱。狀態及輪替時間保存在 `data/source-link-candidates.json`，與已恢復連結一起由同一個資料更新提交保存。152 筆尚無成功詳情核對紀錄不在自動恢复候選內，仍需重新取得可驗證的官方資料。
