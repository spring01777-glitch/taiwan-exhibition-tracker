# 全部場館／地點分類

本次以現有345筆資料整理，原始228種地點／地址組合正規化為186個可選場館／地點：150個具名場館、4個僅有地址的地點、32個來源只填行政區的待確認地點。299筆有具名場館、4筆以地址分類、42筆場館待確認；沒有缺少名稱與地址兩者的活動。

地區未提供的16筆仍保留該地區，不從不完整地址猜城市。每個分類包含地區與地址身分，不同城市或不同地址的同名場所不合併。全部選項依地區連動。

明確歸併例子：金車文藝中心_承德館／金車文藝中心 承德館；府中15的3F、4F、5F展覽室；新浜碼頭藝術空間1F／2F。卡片保留原始展廳、樓層與多空間細節；松菸、華山、駁二按園區分類。未把只填鼓山區等行政區的活動推定為某間館。

文化部同一UID不同showInfo地點已各自形成獨立場地紀錄。園區內多展廳按共同園區分類並完整顯示展廳組合，不把跨倉庫展覽硬指定一個展廳。這輪不額外搜尋全台新活動，也不實作每日場館爬蟲。
